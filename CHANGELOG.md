# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-20

### Added

- Initial release of Astro Terminal Docs starter template
- 8 built-in terminal color scheme presets (Default, Nord, Dracula, Catppuccin, Gruvbox, Solarized, Tokyo Night, One Dark)
- Light and dark mode support (independent of theme selection)
- Theme switcher dropdown in header with live preview
- Theme persistence via localStorage (zero flash on page load)
- MDX content collections with type-safe frontmatter
- Automatic sidebar generation from content directory structure
- Pagefind full-text search with Ctrl+K shortcut
- Responsive layout with mobile hamburger menu
- Copy-to-clipboard buttons on code blocks
- SEO component with Open Graph and Twitter Card meta tags
- Feedback component linking to GitHub Issues
- Tailwind CSS v4 with CSS-first configuration
- CSS custom property token system (`--td-*`) for theming
